# Code of Conduct

[← Home](README.md) · [Contributing](CONTRIBUTING.md)

This project welcomes thoughtful, technically grounded collaboration.

## Expected behavior

- Be respectful and constructive, including when reviewing correctness or security claims.
- Critique code and evidence rather than people.
- Make space for different experience levels and communicate limitations clearly.
- Respect confidentiality, privacy and licenses.

## Unacceptable behavior

Harassment, threats, personal attacks, discriminatory language, publication of another person's private information and deliberately disruptive conduct are not accepted.

## Reporting and enforcement

Report conduct concerns privately to the repository maintainer through an existing private channel. Do not publish sensitive reports in Issues. The maintainer may moderate discussions, request changes, remove inappropriate content or restrict participation according to the severity and context.

This policy applies to repository Issues, pull requests, reviews and other project collaboration spaces.
